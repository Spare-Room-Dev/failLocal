# FailLocal

A playable model of a fictional Pilbara iron ore mine, built to show how a cyber outage propagates through production.
The site is fictional. Every input number carries provenance: sourced, measured or assumed.
`engine/` holds the register schema, the simulation engine and the CLI, as pure TypeScript with no I/O.
Run `npm install`, then `npm test` and `npm run typecheck`.
